# OMAI Agent 🤖

OMAI Agent is an AI-powered assistant built using Python and Streamlit.

## Features

- AI Chat Assistant
- Code Execution
- Memory Storage
- Chat History
- Image Processing
- Data Visualization

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
streamlit run omai_agent.py
```
